# Enterprise and Commercial Pathway

EasyMCP is free to use from this public artifact repository. The public CLI release archives, Docker/Compose examples, docs, and packaged agent skills are MIT licensed unless a file says otherwise.

ab0t builds and sells agent infrastructure. EasyMCP is one public entry point into that platform.

## What Stays Free

You can use the public EasyMCP artifacts for:

- local development
- internal API-to-MCP experiments
- public Docker image usage
- CLI release usage
- examples and docs
- packaged AI agent skills
- non-commercial or commercial internal use under the MIT no-warranty terms

The public MIT license does not require an enterprise subscription.

## Why Teams Buy Enterprise

Teams usually pay when EasyMCP moves from experimentation to production:

- multiple teams need the same MCP gateway patterns
- customers or tenants must be isolated
- auth must align with Okta, Auth0, Azure AD, custom IdPs, or internal auth mesh systems
- API tools need policy, logging, observability, and audit boundaries
- security and procurement need review artifacts
- agent adoption needs support across Codex, Claude, internal agents, and future MCP clients
- production incidents need response guarantees

## Licensing Model

The public repository uses this model:

```text
Public artifacts in this repo
  -> MIT licensed unless a file says otherwise

Private EasyMCP implementation source
  -> not published here
  -> not granted by this public artifact repo
  -> available only if separately agreed in writing

Enterprise services and support
  -> commercial agreement with ab0t
```

The public MIT license is intentionally permissive. Enterprise terms add support, deployment help, security review assistance, private/custom access, and contractual commitments. They do not remove the public MIT rights for artifacts already published in this repo.
