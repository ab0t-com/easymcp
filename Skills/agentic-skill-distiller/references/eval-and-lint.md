# Eval and Lint

## Skill Quality Rubric

Score every skill against these questions:

| Area | Pass condition |
| --- | --- |
| Triggerability | description clearly says when to use the skill |
| Compression | `SKILL.md` contains essentials, not the whole knowledge base |
| Discoverability | references are named by intent and linked from `SKILL.md` |
| Operational safety | secrets, private paths, and destructive commands are excluded or gated |
| Determinism | fragile repeated work has scripts or exact checklists |
| User realism | eval prompts sound like users asking for outcomes |
| Maintenance | volatile details are isolated in references |

## Eval Prompt Set

Write evals as user intent, not keyword search:

```jsonl
{"query":"I need an agent skill that teaches support engineers how to triage failed Docker installs without exposing private source","expected":"public-release-support"}
{"query":"Turn these internal auth notes into a reusable skill for designing OAuth and tenant boundaries","expected":"auth-architect"}
{"query":"This workflow is too long for a prompt. Compress it into a skill with references and tests","expected":"agentic-skill-distiller"}
```

## Common Failure Patterns

- Frontmatter description is too vague to trigger.
- `SKILL.md` repeats long reference content.
- References exist but are not linked from `SKILL.md`.
- The skill includes a README or install guide that should live outside the package.
- Scripts are present but not executable.
- Evals are keyword lists instead of real user tasks.
- Public skills leak internal repo paths, tokens, or implementation-only assumptions.

## Lint Checklist

Before packaging:

1. Read only the frontmatter and ask: would an agent know when to use this?
2. Read `SKILL.md` and ask: can an agent start without opening everything?
3. Open every referenced file and ask: is it necessary and directly linked?
4. Run helper scripts with representative inputs.
5. Scan for unfinished-work markers, secrets, private URLs, private repo paths, and generated bytecode.
6. Package and inspect the archive contents.
