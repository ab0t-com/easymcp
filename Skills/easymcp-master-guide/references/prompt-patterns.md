# Prompt Patterns

## API to Agent

```text
Use $easymcp-api-to-agent to connect this OpenAPI service to Codex. Use safe defaults, render before install, and explain files touched.
```

## Docker Runtime

```text
Use $easymcp-docker-consumer to write a minimal config and docker run command for this OpenAPI URL. Do not put secrets in the config.
```

## Enterprise Profiles

```text
Use $easymcp-enterprise-profiles to design profiles for two customers and production/staging environments. Prefer explicit profile flags and no hidden credential switching.
```

## Auth Architecture

```text
Use $easymcp-auth-architect to map agent-to-MCP auth, MCP-to-downstream auth, tenant claims, and secret storage boundaries for this deployment.
```

## Skill Distillation

```text
Use $agentic-skill-distiller to compress this source material into a concise skill with trigger metadata, one-hop references, helper scripts where useful, and realistic eval prompts.
```

## Public Support

```text
Use $easymcp-public-release-support to troubleshoot this install failure using only public artifacts and redacted logs.
```
