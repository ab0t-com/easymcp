# Release Downloads

Release archives are mirrored here for public visibility and support.

The preferred install path is:

```bash
curl -fsSL https://raw.githubusercontent.com/ab0t-com/easymcp/main/install.sh | bash
```

Expected archive naming:

```text
latest.txt
easymcp_<version>_<os>_<arch>.tar.gz
checksums.txt
```

GitHub Releases may also host the same assets. The installer prefers GitHub Releases and falls back to these mirrored files.

Docker image tags are queried separately from Docker Hub into root `DOCKER_TAGS.md` and `docker-tags.json`.
